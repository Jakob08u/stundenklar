# Stundenklar

Stundenklar prüft Nebenjobs, Ausbildung und duales Studium nach deutschem Recht: Jugendarbeitsschutz, Mindestlohn, Minijob-Grenze, Familienversicherung, Kindergeld. Dazu kommen ein Stundenzettel, ein Berichtsheft und passende Jobs aus der Jobbörse der Bundesagentur für Arbeit, für jede Person geprüft.

- **App:** `index.html`
- **Demo** mit Mia (15), Leon (17) und Sara (20): `demo.html`

Alle Eingaben bleiben im Browser auf dem eigenen Gerät. Der Link-Dienst (Cloudflare Worker) bekommt nur einen Link oder Suchwort und Ort und speichert nichts. Siehe `datenschutz.html`.
